# GESTOR DE TAREAS

Simple gestor de tareas en el que puedes, crear tareas, marcarlas por completadsa, contar cuantas quedan por hacer

## REQUISITOS

- Node.js 22 y npm

## INSTALACIÓN

    git clone git@github.com:Lobillo-24/prueba-examen-despliegue.git
    cd REPO
    npm install

## Uso

    - `npm test` → pasa los tests

- `npm run docs` → genera la documentación en `docs/`

## Documentación
